# Записка о проделанной работе

В ходе написания тестов были выявлены и исправлены следующие недочеты в исходном коде:

1. **Order.Add:** Отсутствовала проверка на пустые строки (null, ""). Добавлена проверка `string.IsNullOrWhiteSpace`.
2. **OrderService.CreateAsync:** При публикации события генерировался новый Guid, который не совпадал с Id созданного заказа. Исправлено: в класс `Order` добавлено свойство `Id`, которое теперь передается в событие.
3. **InMemoryOrderRepository:** Репозиторий не мог найти заказ, так как использовал хэш-код. Исправлено: словарь теперь использует `Order.Id` в качестве ключа.
4. **DiscountCalculator:** Отсутствовала проверка на отрицательную сумму заказа. Добавлено выбрасывание `ArgumentOutOfRangeException`.
